# LazyTex - Sobel EER Texture Optimizer

VRChatアバター向けNDMFプラグイン。Sobel Edge Energy Ratio（EER）を用いてテクスチャのエッジ保持率を評価し、視覚的な劣化を最小限に抑えながら解像度を非破壊で削減します。

## インストール

### VCC（VRChat Creator Companion）

1. [VPM リポジトリを追加](https://hellcat-M18.github.io/vpm-repos/)
2. プロジェクトのパッケージ一覧から **LazyTex** を追加

## 使い方

1. アバターのルートに「LazyTex Optimizer」を追加
2. (任意)プリセットの変更・除外テクスチャの指定
3. PlayModeで結果を確認
